# Intelligent Prompt Routing

- Provides dynamic model selection based on query characteristics
- Routes simple questions to cheaper, faster models (e.g., Claude Haiku) for cost-effective processing
- Routes complex reasoning tasks to more capable models (e.g., Claude Sonnet) for high-quality responses
- Optimizes both cost and performance by matching query complexity to model capabilities
