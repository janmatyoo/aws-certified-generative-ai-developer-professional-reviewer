# Prompt Caching

Caches frequently reused prompt context so repeated requests can be served faster with less repeated foundation model work. Especially useful for customer service systems where many queries are repetitive.

## Use Cases

- Frequently asked questions (FAQs)
- Repetitive inquiry patterns in customer service
- Improving latency and reducing repeated FM load
