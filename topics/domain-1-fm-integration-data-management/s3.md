# Amazon S3

- Hosts data lakes
- System-defined metadata for timestamps provides reliable tracking
- User-defined metadata efficiently stores authorship information
- Hierarchical S3 object tags structure provides multi-level scientific classification
- Provides scalable, secure object storage for documents

## S3 Server Access Logging

- Provides detailed records of requests made to S3 buckets
- Provides an auditable trail for prompt data sources
  - CloudTrail captures Amazon Bedrock API activity including model invocations for usage auditing
  - Prompt Management supports reusable templates, versioning, and lineage tracking for prompts
  - Use to catalog and review I/O metadata

**References:**
- https://docs.aws.amazon.com/AmazonS3/latest/userguide/ServerLogs.html
- https://docs.aws.amazon.com/bedrock/latest/userguide/logging-using-cloudtrail.html
- https://docs.aws.amazon.com/bedrock/latest/userguide/prompt-management.html

## S3 Object Lock

- Protects objects from being deleted or modified for a fixed amount of time or indefinitely
- Helps meet compliance, legal, and retention requirements
- Locks down S3 objects so they cannot be changed or erased
- Ensures GenAI training data, audit logs, or legal documents are immutable and protected — essential for compliance and governance in AI workflows
