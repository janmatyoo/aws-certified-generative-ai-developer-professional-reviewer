# Retrieval-Augmented Generation (RAG)

An architecture pattern that combines foundation models with external data retrieval to ground responses in factual context.

Use RAG knowledge bases to pull in up-to-date product catalog and customer data, which improves accuracy and relevance by grounding responses in company-specific context. Keep the knowledge base current by regularly removing outdated product data.

## Use Cases

- Knowledge-based question answering
- Document-aware chatbots
- Summarization using proprietary data
