# Strands Agents

- Open-source Python SDK for building autonomous AI agents
- Agents use LLMs to reason, plan, and use tools
- Composes and orchestrates multiple specialized GenAI agents
- Streamlines multi-agent patterns that would be difficult to implement through a single agent

## Best Suited For

- Organizations building on AWS infrastructure that want native integration with AWS services for autonomous workflows
- Teams requiring enterprise-grade security, scalability, and compliance features for production autonomous systems
- Projects needing flexibility in model selection across different providers for specialized tasks
- Use cases requiring tight integration with existing AWS workflows for end-to-end autonomous processes

**Reference:** https://docs.aws.amazon.com/prescriptive-guidance/latest/agentic-ai-frameworks/strands-agents.html
