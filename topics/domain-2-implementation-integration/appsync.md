# AWS AppSync

- Fully managed GraphQL API service for building secure APIs to connect frontend apps with data sources
- Lets you add Amazon Bedrock as a data source to an AppSync API
- Can invoke Bedrock synchronously (responses under ~10 seconds) through built-in support
- Supported Bedrock operations include calling Converse (for multi-turn chat) or InvokeModel (for single requests)

**Reference:** https://docs.aws.amazon.com/appsync/latest/devguide/what-is-appsync.html
