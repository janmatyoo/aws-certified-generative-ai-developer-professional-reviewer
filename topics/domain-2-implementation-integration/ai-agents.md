# AI Agents

- Fully managed AWS service that enables developers to create, deploy, and manage autonomous, AI-driven agents capable of executing multi-step business tasks
- Uses the reasoning of foundation models (FMs), APIs, and data to break down user requests, gather relevant information, and efficiently complete tasks

## Pre-processing Prompts

- Has a default pre-processing prompt that determines if user input is safe to use
- Enable default pre-processing prompts in Agents to add an additional layer of security
- Pre-processing prompt evaluates user input before it reaches the FM
- Helps identify and filter potentially malicious prompts

**Reference:** https://docs.aws.amazon.com/bedrock/latest/userguide/advanced-prompts.html
