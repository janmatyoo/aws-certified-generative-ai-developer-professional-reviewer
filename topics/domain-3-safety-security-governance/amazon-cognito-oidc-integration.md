# Amazon Cognito with OIDC Integration

- Provides a secure way to authenticate users through the company's existing IdP
- Exchanges identity tokens for temporary AWS credentials
- Eliminates long-lived credentials
- Allows the application to access Amazon Bedrock using short-term credentials and to integrate with an existing IdP
- Provides comprehensive logging through AWS CloudTrail

**Reference:** https://docs.aws.amazon.com/cognito/latest/developerguide/cognito-user-pools-oidc-idp.html
